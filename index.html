Jak połączyć się z serwerami społeczności?

Wybierz platformę. Instrukcje są ogólne — adres DNS i dodatkowe wymagania sprawdź w źródle danego projektu przy grze.

Konsola

PlayStation 3

Ustawienia sieciowe na konsoli

  1. Otwórz Ustawienia → Ustawienia sieci → Konfiguruj połączenie internetowe.
  2. Wybierz metodę Łatwa lub Własna. Przy konfiguracji własnej pozostaw IP i MTU na automatyczne, a proxy wyłączone.
  3. W ustawieniach DNS wybierz Ręcznie i wpisz główny DNS pokazany przy wybranym projekcie. Zapasowy DNS dodaj tylko, jeśli projekt go podaje.
  4. Zapisz ustawienia, przetestuj połączenie i uruchom grę. Przy problemach wróć do DNS automatycznego i sprawdź instrukcje projektu.
DNS jest zależny od projektu. Przykładowe ustawienia PS Rewired znajdziesz w ich poradniku; nie wpisuj ich dla innych projektów bez potwierdzenia.
Źródło: PS Rewired — konfiguracja PS3 ↗
Emulator

RPCS3

Konfiguracja połączenia w emulatorze

  1. Otwórz Config → Network.
  2. Ustaw Network Status na Connected.
  3. Wybierz DNS Manual i wpisz adres DNS wymagany przez projekt gry.
  4. Ustaw PSN Status zgodnie z wymaganiami projektu (często RPCN). Zapisz zmiany i uruchom grę.
  5. Jeśli projekt udostępnia IP/Host Switches, dodaj tylko jego aktualne wpisy. Ustawienia są zależne od gry.
Instrukcja projektu ma pierwszeństwo — część serwerów działa tylko na prawdziwej konsoli lub wymaga innych ustawień.

Ważne przed zmianą ustawień konsoli

DNS sam w sobie nie gwarantuje działania gry online. Każdy projekt może wymagać aktywnego serwera lub dodatkowej konfiguracji. Statusy pochodzą ze zgłoszeń społeczności i wymagają samodzielnej weryfikacji. Adresy lokalne i niepotwierdzone są wyraźnie opisane.
